# Mobile Crane Services

A responsive mobile crane services landing page for a business operating in Madina, Ghana. The current implementation is a front-end marketing and enquiry website built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

Live demo: https://crane-mobile.vercel.app/

## Project scope
This repository currently implements a front-end enquiry site for the business rather than a full business management platform. The website presents the service offering, contact details, and WhatsApp-based enquiry flow for operators looking to request crane support.

## Features implemented
- Responsive industrial landing page
- Sticky navigation with mobile menu
- Hero section with brand styling and motion effects
- Seven service cards with supporting imagery
- Gallery modal with keyboard navigation
- WhatsApp call-to-action links and contact details
- Contact section and quick enquiry form with validation
- Accessible focus states and reduced-motion support

## Tech stack
- React 19
- Vite 8
- TypeScript
- Tailwind CSS 3
- Framer Motion
- Lucide React
