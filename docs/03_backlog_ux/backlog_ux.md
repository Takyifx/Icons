# D3 Product backlog and UX prototype

## Product backlog
1. Present the business and service offering clearly
2. Provide a working mobile-friendly navigation system
3. Support WhatsApp service enquiries with correct contact details
4. Add a quick enquiry form with validation
5. Provide gallery interaction for crane-related imagery
6. Improve accessibility and responsive layout quality
7. Validate build and test health before release

## Sprint 1 plan
- Goal: stabilise the landing page and improve responsive behaviour
- Work: navigation, form validation, WhatsApp links, accessibility checks
- Completion evidence: build and test runs, UI validation, repository documentation

## UX direction
The current design uses an industrial palette, strong hero messaging, and a dark navy and safety-yellow brand language. The prototype is a landing page and enquiry site, not a full booking management application.

## Acceptance criteria
- Users can navigate the page on mobile and desktop
- Every main service has a relevant image and a contact CTA
- Contact details are correct and clickable
- Gallery modal opens and closes properly
- Form validation blocks missing or invalid data
- Production build succeeds
